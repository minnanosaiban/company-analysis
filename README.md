# 企業分析アプリ

東証の主要企業（約500社）の**有価証券報告書**（EDINET）をもとに、セグメント・財務指標・キャッシュフローを可視化する Streamlit アプリです。
ブログ連載「[株価分析](https://minnanosaiban.github.io/tomo/blog/)」の関連アプリです。

## 画面

| ページ | URL | 内容 |
|---|---|---|
| 🗺️ 業界ポートフォリオ | `/` | 会社別のセグメント別利益を Treemap で一覧（12社ずつ表示） |
| 📊 バリュエーション散布図 | `/valuation` | 財務指標を任意の2軸でプロット。業種で色分け、中央値の十字線、外れ値の除外、会社の強調表示 |
| 💵 CFパターン分類 | `/cashflow` | 営業・投資・財務CFの符号で経営フェーズを8パターンに分類。業種別の構成、少数の会社なら5期の軌跡も |
| 📈 セグメント推移 | `/segments` | 1社のセグメント別5期推移を小さなグラフで並べて表示 |

どのページも、サイドバーの「対象の会社」で、次のように会社を選べます。

- **おすすめ：商社・石油（13社）** … 連載で扱っている会社
- **業種から選ぶ** … 東証33業種
- **会社を選ぶ** … 名前やコードで検索
- **全社**

## 動かし方

Python 3.10 以上が必要です。

```bash
git clone <このリポジトリのURL>
cd company-analysis
pip install -r requirements.txt
streamlit run app.py
```

データ（有報の抽出結果）は `data/` に**同梱**しているので、そのまま動きます。

## データについて

- 元データは、金融庁の **EDINET** に提出された有価証券報告書です。
- `data/yuho/<EDINETコード>/` の JSON は、その XBRL から必要な項目（財務指標・事業セグメント）を抽出・変換したものです。
- `data/companies.csv`（会社一覧）と `data/financials.csv.gz`（全社・全期の財務指標）は、上の JSON から作った集計です。
  会社名・業種（東証33業種）は、東証の銘柄一覧にもとづきます。
- 元の提出書類と異なる場合があります。正確な内容は各社の有価証券報告書をご確認ください。
- **個別財務諸表のみ**の会社（連結を作成しない会社）は、画面に注記を出しています。連結の会社とは基準が異なります。
- セグメント名は、日本語ラベルが整備できていない会社では、英字のキーを区切って表示しています。
- 金融（銀行・保険・証券）は、売上の定義が一般の会社と異なるため、「売上」の欄が空になります。
- 別の会社や期を試すには、同じ形式の JSON を `data/yuho/<EDINETコード>/` に置き、`data/companies.csv` に1行足してください。
  環境変数 `COMPANY_DATA_DIR` で、データのフォルダ（`companies.csv` と `yuho/` がある場所）を指定することもできます。

## 構成

```
app.py                 入口（ナビゲーション・出典の表示）
views/                 各ページ（フォルダ名を pages/ にしないこと。直接リンクで出典の表示が抜けるため）
lib/                   会社一覧・対象の選択・有報JSONの読み込み・出典の表示
data/                  同梱データ
```
